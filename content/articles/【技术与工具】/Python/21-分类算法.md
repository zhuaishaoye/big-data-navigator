## 分类算法的数学基础

### 决策边界理论

分类算法的核心是在特征空间中构建决策边界，将不同类别的样本分离。对于d维特征空间中的二分类问题，决策边界可表示为：

$$h(\mathbf{x}) = \begin{cases} 
1, & \text{if } f(\mathbf{x}) \geq \theta \\
0, & \text{if } f(\mathbf{x}) < \theta 
\end{cases}$$

其中$f(\mathbf{x})$是判别函数，$\theta$是决策阈值。

### 概率估计与贝叶斯决策

分类问题可转化为条件概率估计：

$$P(y=k|\mathbf{x}) = \frac{P(\mathbf{x}|y=k)P(y=k)}{P(\mathbf{x})}$$

最优贝叶斯分类器选择后验概率最大的类别：

$$\hat{y} = \arg\max_k P(y=k|\mathbf{x})$$

## 逻辑回归：线性分类的数学基础

### Sigmoid函数与最大似然估计

逻辑回归通过Sigmoid函数将线性组合映射到概率值：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

其中$z = \mathbf{w}^T\mathbf{x} + b$是线性决策函数。

参数估计通过最大似然估计（MLE）：

$$L(\mathbf{w}) = \prod_{i=1}^{n} [\sigma(\mathbf{w}^T\mathbf{x}_i)]^{y_i} [1-\sigma(\mathbf{w}^T\mathbf{x}_i)]^{1-y_i}$$

对数似然函数为：

$$\ell(\mathbf{w}) = \sum_{i=1}^{n} [y_i \log(\sigma(\mathbf{w}^T\mathbf{x}_i)) + (1-y_i) \log(1-\sigma(\mathbf{w}^T\mathbf{x}_i))]$$

```python
def logistic_regression_theory():
    """逻辑回归理论与实现"""
    # 生成线性可分的二分类数据
    np.random.seed(42)
    n_samples = 1000
    
    # 特征生成
    X = np.random.randn(n_samples, 2)
    
    # 真实决策边界: w1*x1 + w2*x2 + b = 0
    true_w = np.array([1.5, -2.0])
    true_b = 0.5
    
    # 线性组合
    linear_combination = X @ true_w + true_b
    
    # 添加噪声
    noise = np.random.normal(0, 0.2, n_samples)
    y_prob = 1 / (1 + np.exp(-(linear_combination + noise)))
    y = (y_prob > 0.5).astype(int)
    
    return X, y, true_w, true_b
```

### 梯度下降优化算法

逻辑回归可采用梯度上升最大化前文定义的对数似然ℓ，或等价地采用梯度下降最小化负对数似然；以下公式采用梯度上升，后续代码采用负对数似然的梯度下降：

$$\mathbf{w}_{t+1} = \mathbf{w}_t + \alpha \nabla_{\mathbf{w}} \ell(\mathbf{w}_t)$$

梯度公式：

$$\frac{\partial \ell}{\partial \mathbf{w}} = \sum_{i=1}^{n} (y_i - \sigma(\mathbf{w}^T\mathbf{x}_i)) \mathbf{x}_i$$

```python
def train_logistic_regression(X, y, learning_rate=0.01, max_iter=1000):
    """手工实现逻辑回归训练"""
    
    def sigmoid(z):
        # 稳定sigmoid函数，避免数值上溢
        exp_neg_abs = np.exp(-np.abs(z))
        return np.where(z >= 0,
                        1 / (1 + exp_neg_abs),
                        exp_neg_abs / (1 + exp_neg_abs))
    
    def log_likelihood(w, b, X, y):
        z = X @ w + b
        return np.sum(y * z - np.logaddexp(0, z))
    
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0
    
    losses = []
    
    for i in range(max_iter):
        # 前向传播
        z = X @ w + b
        predictions = sigmoid(z)
        
        # 计算损失
        loss = -log_likelihood(w, b, X, y) / n_samples
        losses.append(loss)
        
        # 计算梯度
        dw = (X.T @ (predictions - y)) / n_samples
        db = np.mean(predictions - y)
        
        # 更新参数
        w -= learning_rate * dw
        b -= learning_rate * db
        
        if i % 100 == 0:
            print(f"Iteration {i}, Loss: {loss:.4f}")
    
    return w, b, losses
```

## 决策树：信息理论与递归分割

### 信息增益与熵的计算

决策树通过递归分割构建，每次选择最优特征和分割点。衡量指标包括：

**熵(Entropy)**：
$$H(S) = -\sum_{i=1}^{c} p_i \log_2(p_i)$$

**信息增益(Information Gain)**：
$$IG(S, A) = H(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|} H(S_v)$$

**基尼系数(Gini Index)**：
$$Gini(S) = 1 - \sum_{i=1}^{c} p_i^2$$

```python
def decision_tree_fundamentals():
    """决策树理论实现"""
    
    def entropy(y):
        """计算熵"""
        _, counts = np.unique(y, return_counts=True)
        probabilities = counts / len(y)
        return -np.sum(probabilities * np.log2(probabilities + 1e-10))
    
    def gini_impurity(y):
        """计算基尼系数"""
        _, counts = np.unique(y, return_counts=True)
        probabilities = counts / len(y)
        return 1 - np.sum(probabilities**2)
    
    def information_gain(X, y, feature_idx, threshold):
        """计算信息增益"""
        # 分割数据
        left_mask = X[:, feature_idx] <= threshold
        right_mask = ~left_mask
        
        if np.sum(left_mask) == 0 or np.sum(right_mask) == 0:
            return 0
        
        # 计算加权熵
        n_samples = len(y)
        left_entropy = entropy(y[left_mask])
        right_entropy = entropy(y[right_mask])
        
        weighted_entropy = (np.sum(left_mask) / n_samples * left_entropy + 
                           np.sum(right_mask) / n_samples * right_entropy)
        
        return entropy(y) - weighted_entropy
    
    def find_best_split(X, y):
        """找到最优分割"""
        best_gain = 0
        best_feature = None
        best_threshold = None
        
        n_features = X.shape[1]
        
        for feature_idx in range(n_features):
            thresholds = np.unique(X[:, feature_idx])
            
            for threshold in thresholds:
                gain = information_gain(X, y, feature_idx, threshold)
                
                if gain > best_gain:
                    best_gain = gain
                    best_feature = feature_idx
                    best_threshold = threshold
        
        return best_feature, best_threshold, best_gain
    
    # 生成非线性可分数据
    np.random.seed(42)
    n_samples = 800
    X = np.random.randn(n_samples, 2)
    
    # XOR问题
    y = ((X[:, 0] > 0) ^ (X[:, 1] > 0)).astype(int)
    
    return X, y, find_best_split
```

## 集成学习：Bagging与Bootstrap理论

### 随机森林的数学基础

随机森林结合两种随机化策略：

1. **Bootstrap采样**：从原始数据集中有放回地抽取n个样本
2. **特征随机化**：在每个节点分割时随机选择$\sqrt{p}$个特征

最终预测通过多数投票：

$$\hat{y} = \text{mode}\{h_1(\mathbf{x}), h_2(\mathbf{x}), ..., h_T(\mathbf{x})\}$$

**方差的偏差-方差分解**：

$$\text{Error} = \text{Bias}^2 + \text{Variance} + \text{Noise}$$

随机森林通过集成降低方差，同时保持较低的偏差。

```python
def ensemble_learning_theory():
    """集成学习理论与实现"""
    
    def bootstrap_sample(X, y, random_state=None):
        """生成Bootstrap样本"""
        if random_state is not None:
            np.random.seed(random_state)
        
        n_samples = X.shape[0]
        bootstrap_indices = np.random.choice(n_samples, n_samples, replace=True)
        
        return X[bootstrap_indices], y[bootstrap_indices], bootstrap_indices
    
    def random_forest_from_scratch(X, y, n_trees=10, max_depth=5, min_samples_split=2):
        """从零实现随机森林"""
        
        class SimpleTree:
            def __init__(self, max_depth, min_samples_split):
                self.max_depth = max_depth
                self.min_samples_split = min_samples_split
                self.feature_subset_size = int(np.sqrt(X.shape[1]))
            
            def fit(self, X, y, depth=0):
                self.n_samples = X.shape[0]
                self.n_features = X.shape[1]
                
                # 停止条件
                if (depth >= self.max_depth or 
                    self.n_samples < self.min_samples_split or 
                    len(np.unique(y)) == 1):
                    
                    self.prediction = np.bincount(y).argmax()
                    return self
                
                # 随机选择特征子集
                feature_indices = np.random.choice(
                    self.n_features, self.feature_subset_size, replace=False
                )
                
                # 找到最优分割
                best_gain = 0
                for feature_idx in feature_indices:
                    thresholds = np.unique(X[:, feature_idx])
                    for threshold in thresholds:
                        gain = self._information_gain(X, y, feature_idx, threshold)
                        if gain > best_gain:
                            best_gain = gain
                            self.feature_idx = feature_idx
                            self.threshold = threshold
                
                if best_gain == 0:
                    self.prediction = np.bincount(y).argmax()
                    return self
                
                # 分割数据
                left_mask = X[:, self.feature_idx] <= self.threshold
                right_mask = ~left_mask
                
                self.left = SimpleTree(self.max_depth, self.min_samples_split)
                self.right = SimpleTree(self.max_depth, self.min_samples_split)
                
                self.left.fit(X[left_mask], y[left_mask], depth + 1)
                self.right.fit(X[right_mask], y[right_mask], depth + 1)
                
                return self
            
            def _information_gain(self, X, y, feature_idx, threshold):
                parent_entropy = self._entropy(y)
                
                left_mask = X[:, feature_idx] <= threshold
                right_mask = ~left_mask
                
                if np.sum(left_mask) == 0 or np.sum(right_mask) == 0:
                    return 0
                
                n_samples = len(y)
                left_entropy = self._entropy(y[left_mask])
                right_entropy = self._entropy(y[right_mask])
                
                child_entropy = (np.sum(left_mask) / n_samples * left_entropy + 
                               np.sum(right_mask) / n_samples * right_entropy)
                
                return parent_entropy - child_entropy
            
            def _entropy(self, y):
                _, counts = np.unique(y, return_counts=True)
                probabilities = counts / len(y)
                return -np.sum(probabilities * np.log2(probabilities + 1e-10))
            
            def predict(self, X):
                if hasattr(self, 'prediction'):
                    return np.full(X.shape[0], self.prediction)
                
                predictions = np.zeros(X.shape[0])
                left_mask = X[:, self.feature_idx] <= self.threshold
                right_mask = ~left_mask
                
                if np.sum(left_mask) > 0:
                    predictions[left_mask] = self.left.predict(X[left_mask])
                if np.sum(right_mask) > 0:
                    predictions[right_mask] = self.right.predict(X[right_mask])
                
                return predictions
        
        # 训练多棵树
        trees = []
        for i in range(n_trees):
            # Bootstrap采样
            X_bootstrap, y_bootstrap, _ = bootstrap_sample(X, y, random_state=i)
            
            # 训练单棵树
            tree = SimpleTree(max_depth, min_samples_split)
            tree.fit(X_bootstrap, y_bootstrap)
            trees.append(tree)
        
        return trees
    
    def predict_forest(trees, X):
        """随机森林预测"""
        predictions = np.zeros((len(trees), X.shape[0]))
        
        for i, tree in enumerate(trees):
            predictions[i] = tree.predict(X)
        
        # 多数投票
        final_predictions = np.array([np.bincount(predictions[:, i].astype(np.int64)).argmax() 
                                    for i in range(X.shape[0])])
        
        return final_predictions
    
    return bootstrap_sample, random_forest_from_scratch, predict_forest
```

## 支持向量机：间隔最大化理论

### SVM的数学原理

支持向量机目标是找到间隔最大的分离超平面。对于线性可分情况，以下硬间隔公式要求标签编码为$y_i \in \{-1,+1\}$；后续sklearn示例可使用0/1标签，由库内部处理：

**目标函数**：
$$\min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2$$

**约束条件**：
$$y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1, \quad i = 1, 2, ..., n$$

对于非线性情况，使用核函数$K(\mathbf{x}_i, \mathbf{x}_j)$将数据映射到高维空间：

**常用核函数**：
- RBF核：$K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2)$
- 多项式核：$K(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i^T\mathbf{x}_j + c)^d$
- Sigmoid核：$K(\mathbf{x}_i, \mathbf{x}_j) = \tanh(\alpha \mathbf{x}_i^T\mathbf{x}_j + c)$

```python
    r2 = np.random.normal(4, 0.3, n_samples//2)  # 外圈

    x1_inner = r1[:n_samples//2] * np.cos(theta[:n_samples//2])
    x2_inner = r1[:n_samples//2] * np.sin(theta[:n_samples//2])
    
    # 外圈（类别1）
    x1_outer = r2 * np.cos(theta[n_samples//2:])
    x2_outer = r2 * np.sin(theta[n_samples//2:])
    
    X = np.vstack([
        np.column_stack([x1_inner, x2_inner]),
        np.column_stack([x1_outer, x2_outer])
    ])
    
    y = np.hstack([np.zeros(n_samples//2), np.ones(n_samples//2)])
    
    return X, y
```

## 分类性能评估体系

### 混淆矩阵与评估指标

对于二分类问题，混淆矩阵提供完整的性能图像：

|  | 预测正例 | 预测负例 |
|---|---------|---------|
| **实际正例** | TP | FN |
| **实际负例** | FP | TN |

**核心评估指标**：

- **准确率(Accuracy)**：$\frac{TP + TN}{TP + TN + FP + FN}$
- **精确率(Precision)**：$\frac{TP}{TP + FP}$
- **召回率(Recall)**：$\frac{TP}{TP + FN}$
- **F1分数**：$\frac{2 \cdot Precision \cdot Recall}{Precision + Recall}$

### ROC曲线与AUC指标

ROC曲线绘制真正例率(TPR)与假正例率(FPR)的关系：

- **TPR (Sensitivity)**：$\frac{TP}{TP + FN}$
- **FPR**：$\frac{FP}{FP + TN}$

AUC(Area Under Curve)衡量分类器的整体性能，范围为[0,1]，越接近1越好。

类别不平衡是实际应用中的常见问题。SMOTE(Synthetic Minority Oversampling Technique)通过插值生成少数类样本：

```python
def handle_imbalanced_data(X, y, strategy='smote'):
    """处理类别不平衡数据"""
    
    print(f"原始数据类别分布:")
    unique, counts = np.unique(y, return_counts=True)
    for label, count in zip(unique, counts):
        print(f"  类别 {label}: {count} ({count/len(y)*100:.1f}%)")
    
    if strategy == 'smote':
        # SMOTE过采样
        smote = SMOTE(random_state=42)
        X_resampled, y_resampled = smote.fit_resample(X, y)
        
    elif strategy == 'class_weight':
        # 计算类别权重
        class_weights = compute_class_weight('balanced', classes=unique, y=y)
        weight_dict = dict(zip(unique, class_weights))
        print(f"类别权重: {weight_dict}")
        return X, y, weight_dict
    
    print(f"\n{strategy}后类别分布:")
    unique_new, counts_new = np.unique(y_resampled, return_counts=True)
    for label, count in zip(unique_new, counts_new):
        print(f"  类别 {label}: {count} ({count/len(y_resampled)*100:.1f}%)")
    
    return X_resampled, y_resampled, None

def compare_imbalanced_strategies(X, y):
    """比较不同的不平衡处理策略"""
    
    strategies = {
        'Original': (X, y, None),
        'SMOTE': handle_imbalanced_data(X, y, 'smote'),
        'Class Weight': handle_imbalanced_data(X, y, 'class_weight')
    }
    
    results = {}
    
    for name, (X_data, y_data, weights) in strategies.items():
        X_train, X_test, y_train, y_test = train_test_split(
            X_data, y_data, test_size=0.2, random_state=42, stratify=y_data
        )
        
        # 使用随机森林
        if weights:
            model = RandomForestClassifier(class_weight=weights, random_state=42)
        else:
            model = RandomForestClassifier(random_state=42)
        
        model.fit(X_train, y_train)
        y_pred = model.predict(X_test)
        
        # 计算各类别的F1分数
        f1_scores = f1_score(y_test, y_pred, average=None)
        
        results[name] = {
            'model': model,
            'f1_scores': f1_scores,
            'macro_f1': f1_score(y_test, y_pred, average='macro'),
            'weighted_f1': f1_score(y_test, y_pred, average='weighted')
        }
        
        print(f"{name}:")
        print(f"  各类别F1: {f1_scores}")
        print(f"  宏平均F1: {results[name]['macro_f1']:.3f}")
        print(f"  加权平均F1: {results[name]['weighted_f1']:.3f}\n")
    
    return results
```

```python
def create_customer_churn_dataset():

    data = {
        'tenure': np.random.exponential(24, n_customers),  # 在网时长(月)
        'monthly_charges': np.random.gamma(2, 35, n_customers),  # 月消费
        'total_charges': np.random.exponential(1200, n_customers),  # 总消费
        'age': np.random.normal(45, 15, n_customers),  # 年龄
        'contract_type': np.random.choice([0, 1, 2], n_customers, p=[0.5, 0.3, 0.2]),  # 合同类型
        'payment_method': np.random.choice([0, 1, 2, 3], n_customers),  # 支付方式
        'internet_service': np.random.choice([0, 1, 2], n_customers),  # 网络服务
        'tech_support': np.random.choice([0, 1], n_customers),  # 技术支持
        'online_security': np.random.choice([0, 1], n_customers),  # 在线安全
        'device_protection': np.random.choice([0, 1], n_customers),  # 设备保护
    }
    
    df = pd.DataFrame(data)
    
    # 确保合理范围
    df['tenure'] = np.clip(df['tenure'], 1, 72)
    df['monthly_charges'] = np.clip(df['monthly_charges'], 20, 150)
    df['age'] = np.clip(df['age'], 18, 80)
    
    # 构建流失概率（基于业务逻辑）
    churn_logit = (
        -2.0 +  # 基础截距
        -0.05 * df['tenure'] +  # 在网时间越长越不容易流失
        0.02 * df['monthly_charges'] +  # 费用越高越容易流失
        -0.0001 * df['total_charges'] +  # 总消费高的客户价值高
        -0.01 * df['age'] +  # 年龄大的相对稳定
        0.8 * (df['contract_type'] == 0) +  # 月付客户易流失
        0.3 * (df['payment_method'] == 0) +  # 电子支票易流失
        -0.5 * df['tech_support'] +  # 有技术支持不易流失
        -0.3 * df['online_security']  # 有安全服务不易流失
    )
    
    # 添加随机噪声
    churn_logit += np.random.normal(0, 0.5, n_customers)
    
    # 转换为概率并生成标签
    churn_prob = 1 / (1 + np.exp(-churn_logit))
    df['churn'] = np.random.binomial(1, churn_prob)
    
    print(f"数据集信息:")
    print(f"  客户数量: {len(df)}")
    print(f"  流失率: {df['churn'].mean():.2%}")
    print(f"  特征数量: {len(df.columns) - 1}")
    
    return df

            mask = risk_groups == risk_level
            actual_churn_rate = y_test[mask].mean() if mask.sum() > 0 else 0
            print(f"  {risk_level}: {mask.sum()} 客户, 实际流失率: {actual_churn_rate:.1%}")
    
    return best_model_name, net_benefit
```

```python
def create_model_monitoring_framework():
    """创建模型监控框架"""
    
    class ChurnModelMonitor:
        def __init__(self, model, scaler, feature_cols, baseline_metrics):
            self.model = model
            self.scaler = scaler
            self.feature_cols = feature_cols
            self.baseline_metrics = baseline_metrics
            self.prediction_log = []
        
        def predict_and_log(self, X_new, y_true=None):
            """预测并记录"""
            # 预处理
            X_scaled = self.scaler.transform(X_new)
            
            # 预测
            predictions = self.model.predict(X_scaled)
            probabilities = self.model.predict_proba(X_scaled)[:, 1]
            
            # 记录预测结果
            log_entry = {
                'timestamp': pd.Timestamp.now(),
                'n_samples': len(X_new),
                'predictions': predictions,
                'probabilities': probabilities,
                'churn_rate_predicted': predictions.mean()
            }
            
            if y_true is not None:
                log_entry.update({
                    'y_true': y_true,
                    'accuracy': accuracy_score(y_true, predictions),
                    'precision': precision_score(y_true, predictions),
                    'recall': recall_score(y_true, predictions),
                    'f1': f1_score(y_true, predictions)
                })
            
            self.prediction_log.append(log_entry)
            
            return predictions, probabilities
        
        def check_data_drift(self, X_new, threshold=0.1):
            """检测数据漂移"""
            drift_detected = []
            
            for i, col in enumerate(self.feature_cols):
                # 简单的统计检验（实际应用中可用KS检验等）
                baseline_mean = 0  # 应该存储训练时的统计量
                baseline_std = 1
                
                current_mean = X_new[:, i].mean()
                current_std = X_new[:, i].std()
                
                mean_shift = abs(current_mean - baseline_mean) / baseline_std
                std_shift = abs(current_std - baseline_std) / baseline_std
                
                if mean_shift > threshold or std_shift > threshold:
                    drift_detected.append({
                        'feature': col,
                        'mean_shift': mean_shift,
                        'std_shift': std_shift
                    })
            
            return drift_detected
        
        def generate_monitoring_report(self):
            """生成监控报告"""
            if not self.prediction_log:
                print("暂无预测记录")
                return
            
            recent_logs = self.prediction_log[-10:]  # 最近10次预测
            
            print("模型监控报告:")
            print(f"  预测次数: {len(self.prediction_log)}")
            print(f"  最近预测流失率: {recent_logs[-1]['churn_rate_predicted']:.1%}")
            
            if 'accuracy' in recent_logs[-1]:
                recent_accuracy = np.mean([log['accuracy'] for log in recent_logs if 'accuracy' in log])
                print(f"  最近准确率: {recent_accuracy:.3f}")
                print(f"  基线准确率: {self.baseline_metrics.get('accuracy', 'N/A')}")
    
    return ChurnModelMonitor
```
