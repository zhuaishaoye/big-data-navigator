# 📈 描述性统计（Descriptive Statistics）

> [!abstract] 📋 本节概览
> - 🎯 **学习目标**：理解什么是描述性统计，常用指标有哪些，如何用Python实现

> - ⏱️ **预计用时**：10分钟

# 前置知识
> [!note] 📖 **什么是描述性统计？**
> 描述性统计就是用一些简单的数字和图表，把一大堆数据变得一目了然。比如平均分、最高分、最低分、分布图等。

**生活例子：**
- 统计班级同学的成绩，老师会说"平均分是多少，最高分是谁，最低分是谁"，这就是描述性统计。

# 学习目标
1. **思路说明**
   - 用numpy、pandas等库快速计算均值、方差、最大值、最小值等；下方np.var示例使用ddof=1计算样本方差
   - 用matplotlib画图展示分布
2. **前置知识**
   - numpy（科学计算库）
   - pandas（数据分析库，适合表格数据）
   - matplotlib（画图）

3. **代码示例**
```python title="描述性统计常用操作"
import numpy as np
import pandas as pd
# 假设有一组成绩
scores = [88, 92, 79, 93, 85, 90, 91]
# 用numpy
print("均值:", np.mean(scores))
print("方差:", np.var(scores, ddof=1))
print("最大值:", np.max(scores))
print("最小值:", np.min(scores))
# 用pandas
df = pd.DataFrame({'score': scores})
print(df.describe())  # 汇总数值列的常用描述性统计指标

# 用自带成绩数据展示分布（小样本直方图仅供练习）
import matplotlib.pyplot as plt
plt.hist(scores, bins=5, edgecolor="black")
plt.xlabel("score")
plt.ylabel("count")
plt.title("Teaching sample score distribution")
plt.show()
```

> [!tip] 💡 pandas的describe方法
> 对本例的数值列，一行代码就能输出非空值计数、均值、样本标准差、最大/最小值及四分位数；describe默认不输出方差等其他统计指标。
