# 条形图与饼图学习
> [!note] 📖 **什么是条形图和饼图？**
> 条形图用来比较不同类别的数据多少，饼图用来展示各部分占整体的比例。

**生活例子：**
- 条形图：统计班级里不同血型人数，A型、B型、O型、AB型分别多少人。
- 饼图：统计你一天时间分配，学习、娱乐、睡觉各占多少比例。

## 🛠️ 条形图与饼图绘制
1. **思路说明**
   - 用matplotlib库的bar和pie函数分别绘制
2. **绘图工具**
   - matplotlib（最常用的Python绘图库）

3. **代码示例**
```python title="条形图和饼图绘制示例"
import matplotlib.pyplot as plt
# 条形图
labels = ['A型', 'B型', 'O型', 'AB型']
counts = [12, 8, 15, 5]
plt.bar(labels, counts, color='lightgreen')
plt.ylabel('人数')
plt.title('班级血型分布条形图')
plt.show()

# 饼图
sizes = [8, 6, 10]
labels = ['学习', '娱乐', '睡觉']
plt.pie(sizes, labels=labels, autopct='%1.1f%%', startangle=90)
plt.title('一天时间分配饼图')
plt.axis('equal')
plt.show()
```

> [!tip] 💡 饼图的使用建议
> 饼图适合展示比例关系，类别不宜过多，否则难以分辨。
