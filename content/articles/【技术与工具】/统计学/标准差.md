# 🟢 标准差（Standard Deviation）

> [!abstract] 📋 本节概览
> - 🎯 **学习目标**：理解什么是标准差，为什么要用标准差，以及如何用Python计算标准差
> - 📚 **前置知识**：方差、描述性统计
> - ⏱️ **预计用时**：8分钟

# 学习目标
> [!note] 📖 **什么是标准差？**
> 标准差是方差的平方根，也用来衡量数据的"分散"程度。标准差越大，数据越分散；标准差越小，数据越集中。

**生活例子：**
- 如果你和朋友的身高都差不多，标准差就小。
- 如果有的很高有的很矮，标准差就大。

## 🛠️ 前置知识
1. **思路说明**
   - 先算出方差
   - 对方差开平方，得到标准差
2. **前置知识**
   - numpy（科学计算库，适合大数据量）
   - 也可以用Python自带的math.sqrt

3. **代码示例**
```python title="计算标准差的两种方法"
# 方法1：用Python自带代码
import math
scores = [90, 92, 88, 91, 89]
mean = sum(scores) / len(scores)
var = sum((x - mean) ** 2 for x in scores) / (len(scores) - 1)
std = math.sqrt(var)
print("标准差:", std)

# 方法2：用numpy库
import numpy as np
std_np = np.std(scores, ddof=1)
print("用numpy计算的标准差:", std_np)
```

> [!tip] 💡 标准差和方差的关系
> 标准差=方差的平方根，单位和原数据一致，更直观。
