# 🛠️ 统计学在数据分析中的应用（Statistics in Data Analysis）

> [!abstract] 📋 本节概览
> - 🎯 **学习目标**：了解统计学在各类数据分析场景中的实际作用

# 学习目标
> [!note] 📖 **统计学在数据分析里怎么用？**
> 统计学是"数据分析的工具箱"，贯穿数据收集、整理、分析、建模、决策等每一步。

**生活例子：**
- 电商分析用户留存、金融做风险建模、医学做药物实验，都离不开统计学。

# 工具与练习
- 用pandas、numpy做数据整理和描述统计
- 用scipy做独立样本t检验（条件见上方说明）
- 用matplotlib、seaborn做可视化

```python title="数据分析中的统计学应用"
import numpy as np
import pandas as pd
from scipy.stats import ttest_ind
import matplotlib.pyplot as plt
import seaborn as sns
# 假设有两组销量数据
before = [100, 102, 98, 101, 99, 97, 100]
after = [110, 115, 112, 118, 117, 113, 116]
# 数据整理与描述统计：一行代表一次独立观测，组标签仅用于教学
df = pd.DataFrame({"group": ["before"] * len(before) + ["after"] * len(after),
                   "sales": before + after})
print(df.groupby("group")["sales"].describe())
print("两组均值:", np.mean(before), np.mean(after))
# t检验
print(ttest_ind(before, after))
# 可视化
plt.boxplot([before, after], labels=['广告前', '广告后'])
plt.show()
# 同一份教学数据的seaborn绘图练习
sns.boxplot(data=df, x='group', y='sales')
plt.show()
```
