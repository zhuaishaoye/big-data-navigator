# 学习目标
> [!note] 📖 **什么是连续分布？**
> 连续分布用于描述在连续取值范围内变化的随机变量，比如常用连续模型近似描述的身高、体重、温度。指定单个值的概率为0；对于这里介绍的常见连续分布，区间概率由概率密度函数在该区间上的积分计算。

**生活例子：**
- 身高可以是170.1cm、170.11cm……
- 温度可以是25.0℃、25.01℃、25.001℃……

## 🛠️ 学习目标
1. **思路说明**
   - 用numpy或scipy.stats生成连续分布数据
   - 常见连续分布有：正态分布、均匀分布、指数分布等
2. **学习目标**
   - numpy（生成随机数）
   - scipy.stats（各种概率分布）

3. **代码示例**
```python title="正态分布与均匀分布示例"
import numpy as np
from scipy.stats import norm, uniform
# 正态分布：均值0，标准差1
norm_data = norm.rvs(loc=0, scale=1, size=1000)
# 均匀分布：区间[0,1]
uniform_data = uniform.rvs(loc=0, scale=1, size=1000)
print("正态分布样本前10个:", norm_data[:10])
print("均匀分布样本前10个:", uniform_data[:10])
```

> [!tip] 💡 连续分布的取值受其取值范围限制；能否取小数并不是区分连续分布与离散分布的标准。
