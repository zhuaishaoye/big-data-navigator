# 相关分析学习
> [!note] 📖 **什么是相关分析？**
> 相关分析就是"看两个变量是不是有关系"。比如身高和体重，学习时间和考试分数。

**生活例子：**
- 你发现学习时间越长，考试分数越高，这就是正相关。
- 冰淇淋销量和气温也有相关性，天越热卖得越多。

## 🛠️ 相关分析练习
1. **思路说明**
   - 用numpy或pandas计算相关系数
   - 用matplotlib画散点图直观展示关系
2. **学习目标**
   - numpy（科学计算库）
   - pandas（数据分析库）
   - matplotlib（画图）

3. **代码示例**
```python title="相关系数与散点图"
import numpy as np
import matplotlib.pyplot as plt
x = np.array([1, 2, 3, 4, 5])  # 学习时间
y = np.array([2, 4, 5, 4, 5])  # 考试分数
corr = np.corrcoef(x, y)[0, 1]
print("相关系数:", corr)
plt.scatter(x, y)
plt.xlabel('学习时间')
plt.ylabel('考试分数')
plt.title('相关分析散点图')
plt.show()
```

> [!tip] 💡 这里计算的是皮尔逊相关系数r：越接近1或-1，线性相关越强；接近0表示线性相关较弱，但不能排除非线性关系。相关性不等于因果关系。
