# 抽样误差与偏差
> [!note] 📖 **什么是抽样误差和偏差？**
> 抽样误差是"样本和总体之间的偶然差异"，偏差是"抽样方法本身带来的系统性错误"。

**生活例子：**
- 你随机抽查10个同学的成绩，平均分和全班平均分可能有点差距，这就是抽样误差。
- 如果你只抽成绩好的同学，结果就会偏高，这就是偏差。

## 🛠️ 学习目标
1. **思路说明**
   - 用numpy生成总体数据
   - 多次随机抽样，计算样本均值与总体均值的差异（误差）
   - 模拟有偏抽样，观察均值偏离
2. **常用类库**
   - numpy（生成数据、抽样）

3. **代码示例**
```python title="抽样误差与偏差模拟"
import numpy as np
# 总体：10000个学生成绩，均值80，标准差5
population = np.random.normal(80, 5, 10000)
# 抽样误差
errors = []
for _ in range(1000):
    sample = np.random.choice(population, 30)
    errors.append(np.mean(sample) - np.mean(population))
print("抽样误差均值:", np.mean(errors))
# 偏差模拟：只抽成绩>85的学生
biased_sample = np.random.choice(population[population>85], 30)
print("有偏样本均值:", np.mean(biased_sample))
print("总体均值:", np.mean(population))
```

> [!tip] 💡 在随机抽样条件下，增加样本量通常可以减小抽样误差的典型幅度，但不能保证某一次抽样的误差更小，也不能自动消除抽样偏差。改进抽样设计，或在适用条件下进行加权与统计调整，可以减轻部分偏差，但不保证完全消除。
