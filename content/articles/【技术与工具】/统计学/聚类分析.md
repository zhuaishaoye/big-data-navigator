# 学习目标
> [!note] 📖 **什么是聚类分析？**
> 聚类分析就是"把一堆东西按相似性自动分组"，比如把顾客分成不同类型。

**生活例子：**
- 电商平台根据用户购买行为，把用户分成"爱买便宜货""高端用户""潜力用户"等。
- 医院根据病人症状，把病人分成不同疾病类型。

## 🛠️ 聚类分析方法
1. **思路说明**
   - 用sklearn库的KMeans方法进行聚类分析
   - 选择聚类数，训练模型，查看每个样本的类别
2. **常用类库**
   - sklearn（机器学习库，含聚类方法）
   - numpy、pandas（数据处理）

3. **代码示例**
```python title="KMeans聚类分析示例"
import numpy as np
from sklearn.cluster import KMeans
X = np.array([[1, 2], [1, 4], [1, 0], [10, 2], [10, 4], [10, 0], [1, 2], [1, 4], [1, 0], [10, 2], [10, 4], [10, 0]])
kmeans = KMeans(n_clusters=2, random_state=0).fit(X)
print("每个样本的聚类类别:", kmeans.labels_)
print("聚类中心:", kmeans.cluster_centers_)
```

> [!tip] 💡 聚类分析常用于市场细分、图像分割、异常检测等场景。
