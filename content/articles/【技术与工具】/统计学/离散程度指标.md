# 📏 离散程度指标（Measures of Dispersion）

> [!abstract] 📋 本节概览
> - 🎯 **学习目标**：掌握常用的离散程度指标及其意义与Python实现
> - 📚 **前置知识**：描述性统计
> - ⏱️ **预计用时**：6分钟

# 学习目标
> [!note] 📖 **什么是离散程度？**
> 离散程度就是"数据有多分散"，比如大家分数都差不多，离散程度就小；分数差很大，离散程度就大。

**生活例子：**
- 班级分数都在90分左右，离散程度小。
- 有人考60，有人考100，离散程度大。

## 🎯 学习目标

| 指标     | 说明               | 适用场景           |
|---|---|---|
| 极差     | 最大值-最小值      | 快速了解波动范围   |
| 方差     | 总体方差为各值与均值的平方差均值；样本方差通常以n−1作分母 | 统计分析基础       |
| 标准差   | 相应方差的平方根    | 直观反映波动性     |
| 四分位差 | 四分位数间距        | 抗异常值能力强     |

## 🏢 应用场景
- 数据波动性分析
- 风险评估与质量控制
- 异常值检测

# 前置知识
- 用NumPy计算极差、方差、标准差和四分位差。下例的方差与标准差使用ddof=1，以n−1作分母；若将这些数据视为完整总体，则使用ddof=0，以n作分母。

```python title="离散程度指标计算"
import numpy as np
scores = [90, 92, 88, 91, 89]
print("极差:", np.max(scores) - np.min(scores))
print("方差:", np.var(scores, ddof=1))
print("标准差:", np.std(scores, ddof=1))
q1 = np.percentile(scores, 25)
q3 = np.percentile(scores, 75)
print("四分位差:", q3 - q1)
```
