# 学习目标
> [!note] 📖 **什么是皮尔逊相关系数？**
> 皮尔逊相关系数用来衡量两个连续变量之间的"线性关系"强弱。取值范围-1到1，1表示完全正相关，-1表示完全负相关，0表示无线性关系。

**生活例子：**
- 假设记录每天的学习时间和考试分数，且样本点接近一条正斜率直线，则相关系数接近1；仅有“时间越多分数越高”的趋势，不能确定相关系数接近1。
- 如果学习时间和分数没啥关系，相关系数接近0。

## 🛠️ 皮尔逊相关系数计算
1. **思路说明**
   - 计算两个变量的均值和标准差
   - 对每对数据，计算两个变量各自减去均值后的离均差乘积，并求和
   - 用公式或用库函数直接计算
2. **学习目标**
   - scipy.stats（科学计算库，专门做统计分析）
   - numpy也可以

3. **代码示例**
```python title="计算皮尔逊相关系数"
import numpy as np
from scipy.stats import pearsonr
x = [1, 2, 3, 4, 5]
y = [2, 4, 6, 8, 10]
# 方法1：用numpy
r_np = np.corrcoef(x, y)[0, 1]
print("numpy相关系数:", r_np)
# 方法2：用scipy
r, p = pearsonr(x, y)
print("scipy相关系数:", r, "p值:", p)
```

> [!tip] 💡 p值的含义
> 在观测独立且满足相应检验条件时，pearsonr默认返回检验总体Pearson相关系数为0的双侧p值；其默认精确检验采用正态分布假设。在这些条件下，p值越小，数据与零相关假设越不相容。若事先采用0.05作为显著性水平，p<0.05可判为统计显著，但不表示相关很强，也不证明因果关系。
