# 学习目标
> [!note] 📖 **什么是概率？**
> 概率就是"某件事发生的可能性有多大"。比如抛一枚公平硬币，在正反面等可能且不考虑硬币立住等情况的模型下，正面朝上的概率是50%。

**生活例子：**
- 天气预报说"明天下雨的概率是30%"，意思是有30%的可能会下雨。
- 抽奖时，中奖概率是1/100，就是100个人里大约有1个人能中奖。

## 🛠️ 学习目标
1. **思路说明**
   - 用random库模拟抛硬币、抽奖等随机事件
   - 统计事件发生的次数，除以总次数，得到事件发生的频率，用它估计概率
2. **学习目标**
   - random（Python自带的随机数库）
   - numpy（生成大量随机数）

3. **代码示例**
```python title="模拟抛硬币的概率"
import random
n = 10000  # 抛硬币次数
heads = 0
for _ in range(n):
    if random.choice(['正面', '反面']) == '正面':
        heads += 1
print("正面频率（概率估计）:", heads / n)
```

> [!tip] 💡 在独立重复、每次正面概率均为50%的模拟条件下，随着模拟次数增多，正面频率偏离理论概率超过给定误差的可能性趋于减小，但不保证每增加一次模拟都会更接近理论概率。
