# 🧪 抽样分布（Sampling Distribution）

# 🌟 通俗解释
> [!note] 📖 **什么是抽样分布？**
> 抽样分布就是"同样的方法反复抽样，每次算出来的统计量（比如平均数）会形成一个新的分布"。

**生活例子：**
- 你从一大箱苹果里，每次随机挑10个，分别算平均重量。多做几次，所有"平均重量"就会形成一个分布，这就是抽样分布。

## 🛠️ Python实现思路
1. **思路说明**
   - 用numpy生成总体数据
   - 多次随机抽样，每次计算样本均值，收集所有均值形成分布
2. **学习目标**
   - numpy（生成数据、抽样）
   - matplotlib（画图）

3. **代码示例**
```python title="抽样分布模拟"
import numpy as np
import matplotlib.pyplot as plt
# 假设总体为10000个苹果，重量正态分布，均值150，标准差10
data = np.random.normal(150, 10, 10000)
sample_means = []
for _ in range(1000):
    sample = np.random.choice(data, 30)  # 每次抽30个
    sample_means.append(np.mean(sample))
plt.hist(sample_means, bins=30, color='skyblue', edgecolor='black')
plt.title('样本均值的抽样分布')
plt.xlabel('均值')
plt.ylabel('频数')
plt.show()
```

> [!tip] 💡 在独立同分布且总体方差有限等条件下，样本量足够大时，样本均值的抽样分布可近似为正态分布，这是经典中心极限定理的应用；并非所有统计量的抽样分布都近似正态。
