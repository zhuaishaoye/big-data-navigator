# 统计分析常用Python代码方法
> [!note] 📖 **统计学有哪些常见陷阱？**
> 统计陷阱就是"看起来有道理，其实容易误导"的分析方式，比如样本不代表整体、混淆相关与因果。

**生活例子：**
- 只调查身边朋友的看法就代表全社会，这就是抽样偏差。
- 发现"冰淇淋销量和溺水人数相关"，但其实是因为夏天热，两者都增加（混淆变量）。

## 🛠️ 常见统计陷阱与Python模拟
| 陷阱类型 | 生活化解释 | Python模拟思路 | 常见统计陷阱与误区方法 |
|---|---|---|---|
| 抽样偏差 | 样本不代表整体 | 用numpy只抽某一类数据 | [[【技术与工具】/统计学/抽样方法.md\|抽样方法]] |
| 混淆相关与因果 | 有关系不等于有因果 | np.corrcoef(x, y) 相关但无因果 | [[【技术与工具】/统计学/相关分析.md\|相关分析]] |
| 极端值影响 | 个别异常值拉高/拉低均值 | 在数据中加入极端值 | 均值和方差 |
| 数据可视化误导 | 图表比例不真实 | matplotlib调整y轴范围 | [[【技术与工具】/统计学/统计图表与可视化.md\|统计图表与可视化]] |

> [!tip] 💡 统计分析时要警惕样本代表性、变量间因果关系、异常值和图表误导。

## 🛠️ Python代码示例：极端值影响
```python title="极端值对均值的影响"
import numpy as np
scores = [80, 82, 81, 79, 78, 150]  # 150为极端值
print("均值:", np.mean(scores))
print("中位数:", np.median(scores))
```
