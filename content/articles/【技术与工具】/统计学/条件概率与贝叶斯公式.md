## 🎯 核心概念

> [!note] 📖 **定义**
> 条件概率描述在已知某事件发生的前提下，另一个事件发生的概率。

## 📐 核心公式详解

### 1. 条件概率公式
```text
P(A|B) = P(A∩B) / P(B)，其中 P(B) > 0
```
**含义**：在事件B发生的条件下，事件A发生的概率

### 2. 贝叶斯公式
```text
P(A|B) = P(B|A) × P(A) / P(B)，其中 P(B) > 0
```
**各项含义**：
- `P(A|B)`：后验概率（已知B发生后A发生的概率）
- `P(B|A)`：似然（在A发生的条件下B发生的概率）
- `P(A)`：先验概率（A的初始概率）
- `P(B)`：边际概率（B的总概率）

> [!tip] 💡 **记忆要点**
> 贝叶斯公式是"已知结果推原因"的利器，通过新证据更新我们对事件概率的认知。

## 🧮 Python实现与计算

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# 基础条件概率计算
def conditional_probability(joint_prob, condition_prob):
    """计算条件概率 P(A|B) = P(A∩B) / P(B)"""
    if condition_prob <= 0:
        raise ValueError("条件事件的概率必须大于0")
    return joint_prob / condition_prob

# 示例：掷硬币问题
print("=== 条件概率示例 ===")
# 假设公平硬币的两次投掷相互独立，求第一次是正面的条件下两次都是正面的概率
joint_prob = 0.25  # P(两次都正面) = 1/4
condition_prob = 0.5  # P(第一次正面) = 1/2
result = conditional_probability(joint_prob, condition_prob)
print(f"P(两次都正面|第一次正面) = {result}")

# 贝叶斯公式实现
def bayes_theorem(likelihood, prior, evidence):
    """贝叶斯公式计算"""
    if evidence <= 0:
        raise ValueError("证据的边际概率必须大于0")
    return (likelihood * prior) / evidence

print("\n=== 贝叶斯公式示例 ===")
# 医学检测问题
prior = 0.01  # P(患病) = 1%
likelihood = 0.95  # P(检测阳性|患病) = 95%
false_positive = 0.05  # P(检测阳性|健康) = 5%
evidence = likelihood * prior + false_positive * (1 - prior)  # P(检测阳性)

posterior = bayes_theorem(likelihood, prior, evidence)
print(f"检测阳性时实际患病概率: {posterior:.1%}")
```

## 🏥 经典应用案例

### 案例1：医学诊断问题

**问题**：某疾病发病率为1%，检测准确率为95%（敏感性95%，特异性95%）。如果检测结果为阳性，患者实际患病的概率是多少？

```python
def medical_diagnosis_demo():
    """医学诊断的贝叶斯应用"""
 # 参数设置
    disease_rate = 0.01  # 疾病发病率1%
    sensitivity = 0.95   # 敏感性95%（真阳性率）
    specificity = 0.95   # 特异性95%（真阴性率）
    
 # 计算检测阳性的总概率
    prob_positive = sensitivity * disease_rate + (1 - specificity) * (1 - disease_rate)
    
 # 贝叶斯公式计算
    prob_disease_given_positive = (sensitivity * disease_rate) / prob_positive
    
    print("医学诊断分析:")
    print(f"疾病发病率: {disease_rate:.1%}")
    print(f"检测敏感性: {sensitivity:.1%}")
    print(f"检测特异性: {specificity:.1%}")
    print(f"检测阳性概率: {prob_positive:.2%}")
    print(f"阳性结果下实际患病概率: {prob_disease_given_positive:.1%}")
    
    return prob_disease_given_positive

actual_disease_prob = medical_diagnosis_demo()
```

### 案例2：垃圾邮件过滤

**应用**：基于邮件中出现的关键词判断是否为垃圾邮件

```python
def spam_filter_demo():
    """垃圾邮件过滤的朴素贝叶斯应用"""
 # 训练数据统计
    spam_emails = 1000
    normal_emails = 4000
    total_emails = spam_emails + normal_emails
    
 # 先验概率
    p_spam = spam_emails / total_emails
    p_normal = normal_emails / total_emails
    
 # 假设某关键词在不同类型邮件中的出现概率
    keyword_in_spam = 0.8    # 关键词在垃圾邮件中出现的概率
    keyword_in_normal = 0.1  # 关键词在正常邮件中出现的概率
    
 # 边际概率：关键词出现的总概率
    p_keyword = keyword_in_spam * p_spam + keyword_in_normal * p_normal
    
 # 贝叶斯公式：出现关键词时是垃圾邮件的概率
    p_spam_given_keyword = (keyword_in_spam * p_spam) / p_keyword
    
    print("\n垃圾邮件过滤分析:")
    print(f"垃圾邮件比例: {p_spam:.1%}")
    print(f"关键词在垃圾邮件中出现率: {keyword_in_spam:.1%}")
    print(f"关键词在正常邮件中出现率: {keyword_in_normal:.1%}")
    print(f"出现关键词时是垃圾邮件的概率: {p_spam_given_keyword:.1%}")

spam_filter_demo()
```

### 案例3：A/B测试中的贝叶斯分析

```python
def ab_test_bayesian_analysis():
    """A/B测试的贝叶斯分析"""
    from scipy import stats
    
 # 模拟A/B测试数据
 # A组：100次展示，10次点击
 # B组：100次展示，15次点击
    
 # 使用Beta(1, 1)作为点击率的均匀先验；这是本示例的先验选择，并非唯一的无信息先验
    alpha_prior, beta_prior = 1, 1
    
 # A组后验分布
    clicks_a, views_a = 10, 100
    alpha_a = alpha_prior + clicks_a
    beta_a = beta_prior + views_a - clicks_a
    
 # B组后验分布
    clicks_b, views_b = 15, 100
    alpha_b = alpha_prior + clicks_b
    beta_b = beta_prior + views_b - clicks_b
    
 # 计算后验均值和等尾可信区间
    mean_a = alpha_a / (alpha_a + beta_a)
    mean_b = alpha_b / (alpha_b + beta_b)
    
    ci_a = stats.beta.interval(0.95, alpha_a, beta_a)
    ci_b = stats.beta.interval(0.95, alpha_b, beta_b)
    
    print("\nA/B测试贝叶斯分析:")
    print(f"A组点击率后验均值: {mean_a:.1%} (95%后验等尾可信区间: {ci_a[0]:.1%}-{ci_a[1]:.1%})")
    print(f"B组点击率后验均值: {mean_b:.1%} (95%后验等尾可信区间: {ci_b[0]:.1%}-{ci_b[1]:.1%})")
    
 # B组优于A组的概率
    n_samples = 10000
    samples_a = np.random.beta(alpha_a, beta_a, n_samples)
    samples_b = np.random.beta(alpha_b, beta_b, n_samples)
    prob_b_better = np.mean(samples_b > samples_a)
    
    print(f"B组优于A组的概率: {prob_b_better:.1%}")

ab_test_bayesian_analysis()
```

## 🎯 实用技巧与注意事项

### 📋 常见误区
1. **混淆P(A|B)和P(B|A)**：条件概率不满足交换律
2. **忽略基础概率**：低发病率时，检测阳性未必真患病
3. **独立性假设**：朴素贝叶斯假设给定类别后各特征条件独立，现实中可能不成立

### 💡 实用建议
- 医学检测结果需结合发病率理解
- 机器学习中注意特征独立性假设
- 商业决策中考虑先验信息的价值
