# 前置知识
> [!note] 📖 **什么是统计图表与可视化？**
> 统计图表和可视化就是"用图形把数据讲清楚"，让复杂数据一目了然。

**生活例子：**
- 成绩单上的条形图、饼图、折线图，都是统计图表。
- 看天气预报时的温度变化曲线，就是可视化。

## 🛠️ Python实现思路
1. **思路说明**
   - 用matplotlib、seaborn等库绘制常见统计图表（柱状图、饼图、折线图、散点图等）
   - 用pandas自带的plot方法也能快速画图
2. **常用类库**
   - matplotlib（基础绘图库）
   - seaborn（美化统计图表）
   - pandas（数据分析与可视化）

3. **代码示例**
```python title="常见统计图表绘制"
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
# 假设有一组成绩
scores = [88, 92, 79, 93, 85, 90, 91]
df = pd.DataFrame({'score': scores})
# 柱状图
plt.bar(df.index, df['score'])
plt.title('成绩柱状图')
plt.show()
# 箱线图
sns.boxplot(y=df['score'])
plt.title('成绩箱线图')
plt.show()
# 散点图
plt.scatter(df.index, df['score'])
plt.title('成绩散点图')
plt.show()
```

> [!tip] 💡 可视化能帮助我们快速发现数据中的规律和异常。
