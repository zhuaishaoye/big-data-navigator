## 🛠️ 案例：广告投放效果分析
1. **背景说明**
   - 假设某公司投放新广告，想知道广告是否让销量提升；以下数值仅作为分析演练的示例数据。
2. **分析流程**
   - 收集广告前后销量数据
   - 用描述性统计分析变化
   - 用t检验判断差异是否显著
   - 用可视化展示结果
3. **Python实现**
```python title="广告投放效果分析"
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import ttest_ind
# 广告前后销量数据
before = [100, 102, 98, 101, 99, 97, 100]
after = [110, 115, 112, 118, 117, 113, 116]
# 描述性统计
print("广告前均值:", np.mean(before))
print("广告后均值:", np.mean(after))
# 统计学在数据分析中的应用学习
t_stat, p_val = ttest_ind(before, after)
print("t统计量:", t_stat, "p值:", p_val)
# 可视化
plt.boxplot([before, after], labels=['广告前', '广告后'])
plt.title('广告投放前后销量对比')
plt.ylabel('销量')
plt.show()
```

> [!tip] 💡 在独立样本、等方差等检验条件成立且显著性水平预先设为0.05时，双侧检验的p值小于0.05表示两组总体均值存在统计学显著差异；即使广告后样本均值更高，也不能仅据此认定广告导致销量提升。
