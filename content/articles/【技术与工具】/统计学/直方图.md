# 前置知识
> [!note] 📖 **什么是直方图？**
> 直方图是一种用来展示一组数据"分布情况"的图表。它把数据分成若干区间（比如0-10、10-20），每个区间有多少数据就画多高的柱子。

**生活例子：**
- 统计班级同学的身高分布，直方图能一眼看出大多数人身高在哪个区间。

## 🛠️ 前置知识
1. **思路说明**
   - 用matplotlib库的hist函数直接绘制
   - 可以设置区间（bins）数量
2. **前置知识**
   - matplotlib（最常用的Python绘图库）
   - numpy（生成模拟数据）

3. **代码示例**
```python title="直方图绘制示例"
import matplotlib.pyplot as plt
import numpy as np
heights = np.random.normal(170, 10, 100)  # 生成100个身高数据
plt.hist(heights, bins=10, color='skyblue', edgecolor='black')
plt.xlabel('身高（cm）')
plt.ylabel('人数')
plt.title('班级身高分布直方图')
plt.show()
```

> [!tip] 💡 bins参数
> bins越多，柱子越细，分布越详细；bins越少，分布越粗略。
