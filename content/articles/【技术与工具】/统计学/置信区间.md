# 学习目标
> [!note] 📖 **什么是置信区间？**
> 置信区间是根据样本构造的总体参数估计范围。比如"95%置信区间是[78, 82]"，其中95%指：在满足统计假设的重复抽样中，按同一方法构造的区间约有95%包含真实均值；不是说真实均值有95%的概率落在这一次得到的区间里。

**生活例子：**
- 民调说"某候选人支持率在45%~55%之间，置信度95%"，就是置信区间。

## 🛠️ 学习目标
1. **思路说明**
   - 用numpy计算样本均值和标准差
   - 用scipy.stats查t分布或正态分布的分位点，计算置信区间
2. **常用类库**
   - numpy（计算均值、统计学）
   - scipy.stats（查分位点）

3. **代码示例**
```python title="置信区间计算"
import numpy as np
from scipy.stats import t
sample = np.array([78, 82, 80, 79, 81, 77, 83, 80, 79, 82])
mean = np.mean(sample)
std = np.std(sample, ddof=1)
n = len(sample)
t_crit = t.ppf(0.975, df=n-1)  # 95%置信区间
ci_low = mean - t_crit * std / np.sqrt(n)
ci_high = mean + t_crit * std / np.sqrt(n)
print(f"95%置信区间: [{ci_low:.2f}, {ci_high:.2f}]")
```

> [!tip] 💡 在置信水平和变异程度等其他条件相同的情况下，样本量越大，置信区间通常越窄，说明估计越精确。
