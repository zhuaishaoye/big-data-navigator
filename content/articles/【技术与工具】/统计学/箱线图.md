# 前置知识
> [!note] 📖 **什么是箱线图？**
> 箱线图是一种用来展示一组数据"分布、极值和异常值"的图表。它像一个盒子，能一眼看出数据的中位数、上下四分位数和异常点。

**生活例子：**
- 比如你统计班级同学的成绩，箱线图能帮你观察成绩的中位数、离散程度和潜在异常点，但单独的箱线图不能识别具体学生，也不能据此判断学生能力。

## 🛠️ 前置知识
1. **思路说明**
   - 用matplotlib库的boxplot函数直接绘制
   - 可以一次画多组数据
2. **前置知识**
   - matplotlib（最常用的Python绘图库）
   - numpy（生成模拟数据）

3. **代码示例**
```python title="箱线图绘制示例"
import matplotlib.pyplot as plt
import numpy as np
scores = np.random.normal(75, 10, 50)  # 生成50个成绩数据
plt.boxplot(scores, vert=True, patch_artist=True)
plt.ylabel('分数')
plt.title('班级成绩箱线图')
plt.show()
```

> [!tip] 💡 异常值
> 箱线图的箱体覆盖第一四分位数至第三四分位数，箱体外的数据不一定是异常值。本例使用Matplotlib默认规则：须延伸至距上下四分位数不超过1.5倍四分位距的最远观测值，须外单独绘出的点是该规则标记的潜在异常点，是否具有实际异常意义还需结合数据背景判断。
