## 🌟 通俗解释
> [!note] 📖 **统计学和数据分析啥关系？**
> 统计学是数据分析的"理论大脑"，数据分析是统计学的"实践手脚"。统计学让数据分析更科学、更靠谱。

**生活例子：**
- 统计学像医生的医学知识，数据分析像医生给病人看病。
- 没有统计学，数据分析就像"盲人摸象"。

## 🛠️ 统计学是什么实践
- 用Python可以把统计学理论变成数据分析的实际操作。
- 常用库：numpy、pandas、scipy、matplotlib

```python title="统计学与数据分析结合示例"
import numpy as np
import matplotlib.pyplot as plt
scores = [88, 92, 79, 93, 85, 90, 91]
plt.hist(scores)
plt.title('成绩分布直方图')
plt.show()
```

## 🎯 核心概念

统计学为数据分析提供理论基础和方法工具，是数据分析师必备的知识体系。

| 统计学作用         | 数据分析环节           |
|---|---|
| 数据描述与总结     | 数据探索 和 可视化      |
| 规律发现与假设检验 | 问题诊断、业务洞察    |
| 推断与预测         | 建模、决策支持        |
