# 前置知识
> [!note] 📖 **什么是散点图？**
> 散点图用来展示两个变量之间的关系，每个点代表一组数据的两个数值。

**生活例子：**
- 比如你画出每个人的"学习时间"和"考试分数"，若两个变量均有变化，且点集中在一条向右上方倾斜的直线附近，通常表示学习时间和分数具有较强的正线性相关，但不能据此认定因果关系。

## 🛠️ 散点图学习
1. **思路说明**
   - 用matplotlib库的scatter函数直接绘制
   - x轴和y轴分别是两个变量
2. **前置知识**
   - matplotlib（最常用的Python绘图库）
   - numpy（生成模拟数据）

3. **代码示例**
```python title="散点图绘制示例"
import matplotlib.pyplot as plt
import numpy as np
x = np.random.randint(1, 10, 30)
y = x * 2 + np.random.normal(0, 2, 30)  # y和x有相关性
plt.scatter(x, y, color='orange')
plt.xlabel('学习时间')
plt.ylabel('考试分数')
plt.title('学习时间与考试分数散点图')
plt.show()
```

> [!tip] 💡 点的分布
> 在两个变量均有变化的情况下，点越集中在一条非水平、非竖直的直线附近，通常表示线性相关越强；这一判断不涵盖非线性关系，也不表示因果关系。
