## 一、R语言的职业定位

### 1.1 国内就业市场的真实情况

```text

数据分析岗（互联网）：  Python >> SQL >> R（约10%岗位要求）
量化研究员（金融）：    Python ≈ R（约40%岗位要求R）
统计师/生统（医药）：   R >> SAS（约60%岗位要求R）
```

### 1.2 R vs Python：务实的选择建议

> [!note] 对于在校学生和转行者
> 如果只能选一门语言，选Python。Python是通用工具，数据处理/ML/Web/脚本化全能；R是专业工具，在统计分析上深度更强。先学好Python，再把R作为统计专项工具补充，是国内就业的最优解。

**R的不可替代优势（截至2026年）：**
- 统计检验和模型诊断工具更完整（t.test/lm诊断图/broom包）
- 生物统计包生态无可匹敌（Bioconductor超过2500个包）
- ggplot2在统计可视化的美观度和系统性上仍领先matplotlib
- R Markdown的可重复研究流程比Jupyter更成熟
- 量化金融领域的quantmod/PerformanceAnalytics等包无Python对等品

## 二、25道R语言面试题（含参考答案）

### 第一部分：基础语法（1-10题）

**1. R中有哪些基本数据类型？**

答：R的六种基本类型：
- `numeric`（双精度浮点数）
- `integer`（整数，需加`L`：`1L`）
- `complex`（复数：`1+2i`）
- `character`（字符串）
- `logical`（逻辑值：`TRUE/FALSE`）
- `raw`（原始字节，少用）

用`class()`查看类型，`typeof()`查看底层存储类型。

**2. 向量、矩阵、列表、数据框的区别？**

```r
# 向量（vector）：同质，一维
vec <- c(1, 2, 3)

# 矩阵（matrix）：同质，二维
mat <- matrix(1:9, nrow = 3)

# 列表（list）：异质，可嵌套
lst <- list(name = "Alice", age = 30, scores = c(90, 85, 92))

# 数据框（data.frame/tibble）：列表的特殊形式，每列等长
df <- data.frame(name = c("Alice", "Bob"), age = c(30, 25))
```

**3. `NA`、`NULL`、`NaN`、`Inf`的区别？**

| 值 | 含义 | 检测函数 |
|----|------|---------|
| `NA` | 缺失值（数据存在但未知） | `is.na()` |
| `NULL` | 空对象（对象不存在） | `is.null()` |
| `NaN` | 非数值（0/0的结果） | `is.nan()` |
| `Inf` | 正无穷（1/0的结果） | `is.infinite()` |

**4. `apply`系列函数各自的用途？**

```r
# apply：对矩阵的行（1）或列（2）应用函数
apply(mat, 1, sum)  # 按行求和
apply(mat, 2, mean) # 按列求均值

# lapply：对列表每个元素应用函数，返回列表
lapply(list(1:3, 4:6), mean)

# sapply：lapply的简化版，尝试返回向量或矩阵
sapply(list(1:3, 4:6), mean)  # 返回 c(2, 5)

# vapply：指定返回类型的sapply（更安全）
vapply(list(1:3, 4:6), mean, numeric(1))

# tapply：按因子分组应用函数
tapply(c(10, 20, 15, 25), c("A", "B", "A", "B"), mean)
```

**5. `for`循环在R中为什么慢？如何优化？**

答：R是解释型语言，`for`循环每次迭代都有函数调用开销；更关键的是，在循环内动态增长向量（`vec <- c(vec, new_val)`）会触发内存重新分配。

优化方法：
1. **向量化操作**：`x + y`代替`for(i in seq) x[i] + y[i]`
2. **预分配内存**：`result <- vector("numeric", n)` 然后填充
3. **使用`purrr::map`或`lapply`**：可改善迭代代码的表达方式，但不保证比预分配的for循环更快；若将20-50%的提速作为测试假设，应在相同数据、函数和运行环境下实测。
4. **`Rcpp`**：将热点代码用C++重写

**6. 如何找到向量中的重复元素？**

```r
x <- c(1, 2, 3, 2, 4, 1, 5)
duplicated(x)       # 返回逻辑向量，标记重复元素（保留第一次出现）
x[duplicated(x)]    # 获取重复的值：c(2, 1)
unique(x)           # 去重
table(x)[table(x) > 1]  # 找出出现超过一次的值及其频次
```

**7. `<<-`和`<-`的区别？**

答：`<-`在当前环境赋值；`<<-`向上查找父环境并在找到该变量的第一个环境中赋值（若未找到则在全局环境创建）。常用于在函数内修改函数外的变量。

```r
counter <- 0
increment <- function() {
  counter <<- counter + 1  # 修改外部counter
}
increment()
cat(counter)  # 输出：1
```

**9. `factor`和`character`的区别？什么时候用factor？**

答：`character`存储原始字符串；`factor`存储分类变量，内部是整数+标签映射，有固定的水平（levels）。

使用factor的场景：
- 建模时需要哑变量（`lm()`会自动把factor转为哑变量）
- 控制分类变量的排序（如月份、教育程度等有序分类）
- 用`forcats`包重新排序因子水平（影响ggplot2图例顺序）

### 第三部分：统计建模（16-20题）

**16. 线性回归的OLS假设是什么？如何在R中检验？**

答：Gauss–Markov条件包括模型对参数线性、解释变量无完全共线性、误差满足零条件均值，以及条件误差协方差矩阵为σ²I（同方差且误差之间不相关）。正态性不是Gauss–Markov定理的必要条件。
1. **对参数线性**：解释变量可以包含变换项，不要求y与每个原始变量都是直线关系。
2. **零条件均值**：E(误差|X)=0，不能仅凭残差检验确认，需要结合研究设计判断。
3. **误差相关性诊断**：`lmtest::dwtest()`可用于特定设定下的一阶自相关诊断，不等于检验全部独立性条件。
4. **同方差性诊断**：`lmtest::bptest()`用于异方差检验。
5. **共线性与分布诊断**：`car::vif(model)`用于评估共线性程度，VIF > 10是经验警示而非统一判定标准；`shapiro.test(residuals(model))`用于残差正态性诊断，正态性主要关联特定有限样本推断。

```r
library(lmtest)
library(car)
model <- lm(y ~ x1 + x2 + x3, data = df)

dwtest(model)      # DW检验
bptest(model)      # BP检验（同方差）
shapiro.test(residuals(model))  # 正态性
vif(model)         # 多重共线性
```

**17. 逻辑回归的系数如何解读？**

答：逻辑回归系数是log-odds（对数几率）。`exp(coef)`是Odds Ratio（OR）：
- OR > 1：该变量每增加1单位，事件发生的几率是原来的OR倍
- OR = 2.5意味着：该因素存在时，事件发生的几率是不存在时的2.5倍

```r
model <- glm(converted ~ age + spend, data = df, family = binomial())
exp(coef(model))           # OR值
exp(confint(model))        # OR的95%置信区间
```

**18. 如何处理不平衡分类问题？**

答：当正负样本比例极度不平衡（如欺诈检测中正例只有0.1%）时：
1. **重采样**：过采样少数类（SMOTE）或欠采样多数类
2. **调整分类阈值**：默认0.5通常不是最优阈值，用ROC曲线选择
3. **使用适当评估指标**：AUC/F1/PR曲线代替Accuracy
4. **代价敏感学习**：给少数类样本更高权重（`weights`参数）

```r
library(themis)  # tidymodels的重采样扩展
rec <- recipe(label ~ ., data = train) %>%
  step_smote(label)  # SMOTE过采样
```

**19. 随机森林与XGBoost的区别？**

| 维度 | 随机森林 | XGBoost |
|------|---------|---------|
| 集成方式 | Bagging（并行） | Boosting（串行） |
| 偏差-方差 | 低方差 | 低偏差 |
| 速度 | 可并行，快 | 串行，但高度优化 |
| 调参难度 | 较少参数 | 参数多，需要调优 |
| 过拟合风险 | 较低 | 较高（需正则化） |
| 缺失值处理 | 需预处理 | 内置处理机制 |

**20. 交叉验证的目的是什么？k值如何选择？**

答：交叉验证估计模型的泛化能力，避免在同一数据集上训练和评估导致的乐观估计。

k值选择：
- k=5或k=10：最常用，偏差-方差的良好平衡
- k=n（LOOCV）：每次留出一个样本，训练集大小为n−1；通常偏差较小，但并非普遍无偏，方差及计算成本取决于数据和模型。
- 分层K折（`vfold_cv(strata=)`）：当类别不平衡时使用，确保每折比例一致

### 路径二：医药/生物信息/临床数据

**典型公司**：CRO公司（药明康德/ICON）、跨国药企（辉瑞/罗氏/阿斯利康）、医院科研部门

**特殊说明**：FDA/NMPA对临床数据的监管要求，推动了R在医药行业的普及。CDISC数据标准（SDTM/ADaM）在R中有专门包支持。

**特点**：薪资相对较低，但学习氛围好，适合对统计研究有兴趣的人。使用R主要用于论文数据分析、元分析、心理测量等。
