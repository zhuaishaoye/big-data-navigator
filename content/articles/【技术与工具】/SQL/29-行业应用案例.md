## 🧩 案例1：医疗行业——患者就诊统计

### 背景
医院需要统计每位医生本月截至当前时刻的就诊记录条数；该指标不等同于去重患者人数。

### 解题思路
- 用WHERE筛选本月数据
- 用GROUP BY按医生分组，COUNT(*)统计就诊记录条数

### SQL实现
```sql
SELECT 医生ID, COUNT(*) AS 本月接诊数
FROM 就诊记录
WHERE 就诊时间 >= DATE_FORMAT(NOW(), '%Y-%m-01')
  AND 就诊时间 <= NOW()
GROUP BY 医生ID;
```

## 🧩 案例2：教育行业——班级成绩分析

### 背景
学校要找出每个班级的平均分，并筛选出平均分低于70分的班级。

### 解题思路
- 用GROUP BY按班级分组，AVG统计平均分
- 用HAVING筛选低于70分的班级

### SQL实现
```sql
SELECT 班级, AVG(分数) AS 平均分
FROM 学生
GROUP BY 班级
HAVING 平均分 < 70;
```

## 🧩 案例3：金融行业——高价值客户识别

### 背景
银行要找出近一年内存款总额超过10万元的客户。

### 解题思路
- 用WHERE筛选近一年数据
- 用GROUP BY按客户分组，SUM统计存款
- 用HAVING筛选高价值客户

### SQL实现
```sql
SELECT 客户ID, SUM(金额) AS 年存款总额
FROM 存款记录
WHERE 存款时间 >= DATE_SUB(NOW(), INTERVAL 1 YEAR)
  AND 存款时间 <= NOW()
GROUP BY 客户ID
HAVING 年存款总额 > 100000;
```

## 🚦 易错点与小贴士

- 时间筛选要注意格式和时区
- 分组统计后只能查分组字段和聚合函数
- 行业数据表结构可能不同，要灵活调整SQL
