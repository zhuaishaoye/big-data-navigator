# 💾 数据备份与恢复

> [!abstract] 📋 本节概览
> - 🎯 **学习目标**：用最简单的方式理解并会用备份和恢复保护数据安全
> - 📚 **前置知识**：[[【技术与工具】/SQL/24-权限与安全|权限与安全]]
> - ⏱️ **预计用时**：10分钟
> - 🔧 **开发环境**：MySQL/PostgreSQL/[SQL] Server
> - 📊 **数据集**：users、orders等表

## 🌟 通俗解释

数据备份就像"给手机、电脑做备份"，万一丢了还能找回来。

恢复就是"把备份的东西还原回来"，比如手机丢了，换新手机后恢复数据。

在数据库里，备份和恢复就是防止数据丢失、误删、硬盘坏了还能找回来。

## 🧩 语法和例子

- **备份数据库**（以MySQL为例）：
  ```sql
  -- 命令行备份
  mysqldump -u 用户名 -p 数据库名 > 备份文件.sql
  ```
- **恢复数据库**：
  ```sql
  -- 命令行恢复
  mysql -u 用户名 -p 数据库名 < 备份文件.sql
  ```

## 🚦 备份与恢复的常见用法

- 定期备份，防止意外丢失
- 升级、迁移数据库前先备份
- 误删数据后用备份恢复

## ❗ 常见小白易错点

- 忘记定期备份会增加数据丢失风险；若没有可用备份或其他恢复材料，出事后可能无法恢复
- 只备份部分表，漏掉重要数据
- 恢复时覆盖了新数据

## 📚 总结小贴士

- 备份就是"给数据买保险"
- 恢复就是"出事后找回数据"
- 记得定期备份，备份要全、要安全保存

## 📊 学习目标

### 练习1：用命令行备份数据库
```bash
mysqldump -u root -p mydb > mydb_backup.sql
```

### 练习2：用命令行恢复数据库
```bash
mysql -u root -p mydb < mydb_backup.sql
```
