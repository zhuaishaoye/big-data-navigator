# 求职材料自检清单

> [!abstract] 本文定位
> 这是一份投递前检查表。简历、作品集、面试材料，最好都过一遍。
>
> AI 时代求职最怕两件事：一是简历写得太虚，二是作品集做得太散。自检清单就是帮你把材料收紧。

## 一、岗位匹配自检

- [ ] 我是否明确目标岗位，而不是同时投分析、运营、开发、产品、算法所有方向？
- [ ] 我是否拆解过目标 JD 的真实职责？
- [ ] 我是否知道该岗位最看重哪 3 项能力？
- [ ] 我的简历前三分之一是否能体现岗位匹配度？
- [ ] 我的项目是否对应岗位真实任务，而不是只对应工具关键词？

如果没有，先回到 [[【求职就业专题】/08-AI时代求职与作品集/01-AI时代JD拆解与岗位匹配.md|AI时代JD拆解与岗位匹配]]。

## 二、简历自检

### 项目表达

- [ ] 每个项目是否写清楚业务问题？
- [ ] 是否写清楚我做了什么，而不是团队做了什么？
- [ ] 是否有方法、工具和数据来源？
- [ ] 是否体现人的判断，而不是只写 AI 生成？
- [ ] 是否有量化结果？
- [ ] 结果是否能解释清楚怎么算？
- [ ] 是否沉淀了模板、流程、指标、Eval 或策略库？

### AI相关表达

- [ ] 是否避免只写“熟练使用 AI 工具”？
- [ ] 是否写清楚 AI 参与了哪个环节？
- [ ] 是否写清楚如何审查 AI 输出？
- [ ] 是否有 AI 出错案例和修正方法？
- [ ] 是否避免夸大和虚构经历？

## 三、作品集自检

作品集至少要回答：

- [ ] 这个项目解决什么业务问题？
- [ ] 目标用户是谁？
- [ ] 数据从哪里来，口径是什么？
- [ ] AI 参与了哪些环节？
- [ ] 人做了哪些关键判断？
- [ ] 如何防止错误？
- [ ] 结果如何验证？
- [ ] 有哪些复盘和可复用资产？

如果作品集只是一个 Demo、一个截图、一份报告，而没有这些内容，就还不够。

## 四、面试准备自检

对每个核心项目，你都应该能回答：

- [ ] 这个项目为什么要做？
- [ ] 你的角色是什么？
- [ ] 最大难点是什么？
- [ ] 数据口径怎么定义？
- [ ] AI 具体帮了什么？
- [ ] AI 哪里不可靠？
- [ ] 你怎么验证结果？
- [ ] 这个项目的不足是什么？
- [ ] 如果再做一次，你会怎么优化？

建议配合 [[【求职就业专题】/08-AI时代求职与作品集/04-AI时代面试表达与案例讲述.md|AI时代面试表达与案例讲述]] 做模拟面试。

## 五、风险自检

- [ ] 简历中是否存在无法解释的夸大数字？
- [ ] 是否写了没做过的模型、平台、项目？
- [ ] 是否暴露公司敏感数据、客户信息或内部截图？
- [ ] 是否把 AI 生成内容当成真实项目成果？
- [ ] 是否把相关性写成因果？
- [ ] 是否忽略隐私、权限、合规风险？

> [!warning] 最后的底线
> 面试官最怕你不会，第二怕你装会。不会可以补，装会很难救。

## 六、投递前最后一页

建议你为每个目标岗位准备一页“投递说明”：

```text
目标岗位：
岗位核心要求：
我最匹配的三项能力：
对应项目证据：
可能短板：
面试准备重点：
作品集链接：
```

这页不一定给 HR 看，但你自己一定要看。它能防止你盲投，也能让你面试时更有方向。
