# Excel数据分析 - 最通用的数据分析工具

> [!info] 💡 **术语速览**
> **Excel数据分析** = 使用Microsoft Excel进行数据处理、统计分析和可视化展示的基础技能，包括数据透视表、函数应用、图表制作等核心功能，是数据分析的入门工具。

## 🤔 为什么Excel是数据分析的入门工具？

Excel具有以下优势：
- **普及率高**：几乎所有企业都有Excel
- **学习成本低**：界面友好，易于上手
- **功能强大**：支持复杂的数据处理和分析
- **灵活性强**：可以快速调整和修改

## 💡 Excel数据分析核心功能

### 1. 数据处理功能 📊
- **[[【数据分析与数据运营】/98-专业术语词典/04-数据工程类/数据清洗|数据清洗]]**：去重、填充、格式统一
- **数据透视表**：快速汇总和分组分析
- **筛选排序**：快速定位和整理数据
- **查找替换**：批量修改数据

### 2. 统计分析功能 📈
- **描述性统计**：平均值、中位数、标准差
- **相关分析**：CORREL函数分析变量关系
- **[[【数据分析与数据运营】/98-专业术语词典/03-技术算法类/回归分析|回归]]**：线性回归和趋势分析
- **假设检验**：t检验、方差分析

### 3. 数据可视化功能 📊
- **基础图表**：柱状图、折线图、饼图
- **高级图表**：散点图、箱线图、瀑布图
- **动态图表**：结合切片器的交互图表
- **仪表板**：综合展示多个指标

## 🛠️ 实用分析技巧

### 快捷键提效

以下快捷键主要面向Windows桌面版Excel；Alt+D+P为传统菜单快捷序列，不同版本或平台可能不适用。
- Ctrl+T：创建表格
- Alt+D+P：创建数据透视表
- F4：重复上一个操作
- Ctrl+Shift+L：添加筛选器

### 常用函数

以下仅示意函数名称及组合思路，不是可直接运行的公式；实际使用需填写数据范围及必要参数，行内#文字为说明，不属于Excel公式。
```Excel数据处理
# 统计函数
=AVERAGE() # 平均值
=MEDIAN()  # 中位数
=MODE()    # 众数
=STDEV()   # 标准差

# 查找函数
=VLOOKUP() # 垂直查找
=INDEX(MATCH()) # 更强大的查找
=COUNTIF() # 条件计数
=SUMIF()   # 条件求和
```
